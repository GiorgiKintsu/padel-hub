# Padel Hub

პადელის კორტების დაჯავშნის აპლიკაცია Android-ისა და iOS-ისთვის, ქართულ და ინგლისურ ენებზე.

## პროექტის სტრუქტურა

- [`mobile/`](mobile/) — React Native + Expo + TypeScript აპი და მისი გაშვების ინსტრუქციები.
- [`backend/`](backend/) — NestJS + PostgreSQL ბექენდი (ეტაპი A: საფუძველი) და მისი გაშვების ინსტრუქციები.
- [`docs/PADEL_HUB_FULL_DOCUMENTATION.md`](docs/PADEL_HUB_FULL_DOCUMENTATION.md) — შეთანხმებული მოთხოვნები, ბიზნესწესები და პროექტის მიმდინარე მდგომარეობა.
- [`ENVIRONMENT.md`](ENVIRONMENT.md) — სამუშაო გარემოს მოწყობის ინსტრუქციები.

## გაშვება

საჭიროა Node.js და npm.

```sh
cd mobile
npm ci
npm start
```

Android-ზე გამოიყენე ემულატორი ან Expo Go, iPhone-ზე — Expo Go. დეტალური ინსტრუქციები მოცემულია [`mobile/README.md`](mobile/README.md)-ში.

## მიმდინარე მდგომარეობა

შექმნილია სატესტო გზა: მთავარი → კორტები → შეჯამება → ჩემი ჯავშანი. ხელმისაწვდომია სრული და გაყოფილი გადახდის სიმულაცია, დროის ათვლა და ენის გადართვა. ენის არჩევანი მოწყობილობაზე ინახება.

კორტები სატესტო მონაცემებია. გადახდები სიმულაციაა; რეალური თანხა არ იჭრება. ჯავშანი მხოლოდ მიმდინარე სესიაში ინახება. ავტორიზაცია, სერვერი და რეალური გადახდის ინტეგრაცია ჯერ არ არის დანერგილი. სრული დოკუმენტაცია აღწერს როგორც არსებულ მდგომარეობას, ისე დაგეგმილ ფუნქციებს.
