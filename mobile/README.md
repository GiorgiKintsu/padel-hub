# Padel Hub

პადელის კორტების დაჯავშნის აპი Android-ისა და iOS-ისთვის.

## საწყისი მდგომარეობა

React Native + Expo SDK 58 + TypeScript + Expo Router. ამ ეტაპზე არის ოთხეკრანიანი სატესტო გზა: მთავარი → კორტები → შეჯამება → ჩემი ჯავშანი. მუშაობს სრული/გაყოფილი გადახდის სიმულაცია და 5/10-წუთიანი ათვლა. მონაცემები მეხსიერებაშია და reload-ზე იკარგება; რეალური თანხა არ იჭრება და მოწვევები არ იგზავნება. ავტორიზაცია და backend ჯერ არ არსებობს.

პროექტი განახლდა SDK 58-ზე: iPhone-ის კავშირის ჩანაწერში დაფიქსირდა Expo Go 58.0.5 და runtime exposdk:58.0.0. მომხმარებელმა SDK 58-ზე განახლების შემდეგ iPhone-ზე წარმატებით გახსნა დაადასტურა.

## გაშვება

ამ საქაღალდიდან:

```sh
npm install
npm start
```

Android-ის ემულატორის გახსნის შემდეგ:

```sh
npm run android
```

ემულატორის გაშვების მაგალითი (მიუთითე შენი ვირტუალური მოწყობილობის სახელი):

```sh
~/Android/Sdk/emulator/emulator -avd Padel_Hub_API_36 -gpu swiftshader -feature -Vulkan -cores 4 -memory 3072
```

iPhone-ზე: დააყენე Expo Go, ტელეფონი და კომპიუტერი ერთ ქსელში შეაერთე, გაუშვი `npm start` და კამერით დაასკანერე QR კოდი. `--localhost` მხოლოდ ამ კომპიუტერის ემულატორისთვის გამოიყენე; ტელეფონი კომპიუტერის localhost-ს ვერ დაუკავშირდება. Linux-ზე iOS Simulator არ მუშაობს.

## შემოწმებები

```sh
npm run check      # lint + typecheck + ტესტები ერთად
npx expo-doctor
```

ცალ-ცალკე: `npm run lint`, `npm run typecheck`, `npm test`. ტესტები (`tests/*.test.cjs`) Node-ის ჩაშენებული test runner-ით ეშვება და დომენსა და თარგმანებს ამოწმებს; დამატებითი პაკეტი არ სჭირდება.

## კოდის სტრუქტურა

დამოკიდებულება ერთი მიმართულებითაა: ეკრანი → ფუნქციის კომპონენტები → დომენი. დომენმა React-ის შესახებ არაფერი იცის.

- `src/app/` — მხოლოდ მარშრუტები. თითო ეკრანი აწყობს მზა კომპონენტებს და წყვეტს, სად გადავიდეს მომხმარებელი.
  - `_layout.tsx` — პროვაიდერები, Stack და მუდმივი ქვედა ნავიგაცია.
  - `index.tsx`, `courts.tsx`, `checkout.tsx`, `booking.tsx` — სატესტო დაჯავშნის გზა.
- `src/features/booking/domain/` — სუფთა TypeScript, React-ის გარეშე; სწორედ ამას ამოწმებს ტესტები.
  - `units.ts` — ერთეულების სახელები (`Tetri`, `MinuteOfDay`, `DayKey`, `Timestamp`), რომ ფუნქციის ხელმოწერიდან ჩანდეს, რას ელის.
  - `courts.ts` — კორტის ტიპი და სატესტო მონაცემები.
  - `schedule.ts` — `Search` (რა სურს მოთამაშეს) და `Slot` (კონკრეტული კორტი და ზუსტი დრო), თავისუფალი დროები და „საუკეთესო ვარიანტების“ დალაგება.
  - `payment.ts` — ფასი, ჯავშნის მდგომარეობები (5/10-წუთიანი ვადები, წილები, დაფარვა) და ერთი მიმდინარე ჯავშნის reducer. ჯავშნის დაწყების წესებიც აქაა: აქტიური ჯავშნის გადაწერა, დახურული სლოტი ან არასწორი გაყოფა დომენშივე იბლოკება, არა მხოლოდ ღილაკით.
  - `format.ts` — საათის, თანხისა და ათვლის ტექსტად ჩვენება.
- `src/features/booking/context.ts` — `BookingStore`: ყველაფერი, რისი წაკითხვა ან გაკეთებაც ეკრანს შეუძლია, და `useBooking()`. `provider.tsx` — მისი სესიური განხორციელება; მხოლოდ ის კითხულობს მოწყობილობის საათს და დროს მოვლენას ატანს.
- `src/features/booking/use-court-options.ts` — ერთადერთი ადგილი, რომელმაც იცის, საიდან მოდის კორტები. დღეს ეს სატესტო მონაცემებია; რეალური კალენდრის გაჩენისას მხოლოდ ეს ფაილი შეიცვლება.
- `src/features/booking/components/` — დაჯავშნის ეკრანების ნაწილები: ძიების ბარათი, კორტის ბარათი, ათვლა, გადახდის სია.
- `src/components/ui/` — საერთო ელემენტები: `Button`, `Chip`, `Card`, ტექსტის სტილები, `Badge` და `Notice` (ტონებით: lime / neutral / warning / danger), `ProgressBar`, `Icon`. `src/components/screen.tsx` — ეკრანის ჩარჩო ენის კომპაქტური გადამრთველით; `tab-bar.tsx` — ქვედა ნავიგაცია.
- აიკონები: `components/ui/icon.tsx`-ში ჩამოთვლილი ნაკრები `expo-symbols`-ით — iOS-ზე SF Symbols, Android-სა და ვებზე Material Symbols. ახალი აიკონი ჯერ ამ სიას ემატება.
- `src/i18n/` — `locales/ka.ts` და `locales/en.ts` (თითო ხაზზე ერთი ტექსტი), `translate.ts`, `dates.ts`, ენის პროვაიდერი და `useLanguage()`.
- `src/theme.ts` — დიზაინის ტოკენები: ფერები, მომრგვალების რადიუსები და ჩრდილები. `src/hooks/use-now.ts` — მიმდინარე დრო, როგორც React-ის მდგომარეობა.
- `app.json` — აპის სახელი და Expo-ს პარამეტრები.

წესები, რომლებიც ამ სტრუქტურას ინარჩუნებს:

- თანხა ყველგან თეთრებშია (მთელი რიცხვი); ლარად მხოლოდ `money()` აქცევს.
- დრო დომენში არგუმენტად გადაეცემა (`now`); `Date.now()` კომპონენტის render-ში არ იძახება — ამისთვის არის `useNow()`.
- ახალი ტექსტი ემატება `ka.ts`-ს და `en.ts`-ს; გამოტოვებულ თარგმანს typecheck დაიჭერს.
- ფერი, რადიუსი და ჩრდილი კომპონენტში პირდაპირ არ იწერება — ემატება `theme.ts`-ს.
- ტექსტი დიდ ასოებად (`uppercase`) არ გარდაიქმნება: ქართულს რეგისტრი არ აქვს და ზოგ მოწყობილობაზე ასოები დაიკარგება.
- ფენების საზღვრებს `eslint.config.js` აიძულებს: დომენი ვერ შემოიტანს React-ს, Expo-ს ან UI-ს; საერთო კოდი (`components`, `hooks`, `i18n`) ვერ შემოიტანს ფუნქციას ან ეკრანს; ფუნქცია ვერ შემოიტანს ეკრანს. დარღვევა lint-ის შეცდომაა.
- TypeScript მკაცრ რეჟიმშია, მათ შორის `noUncheckedIndexedAccess`: მასივის ელემენტი შეიძლება არ არსებობდეს და კოდმა ეს უნდა გაითვალისწინოს.
- `../ENVIRONMENT.md` — გარემოს მოწყობის ინსტრუქციები.

პროექტი ჯერ არ არის გამოქვეყნებული და სხვა კომპიუტერთან სინქრონიზაცია არ არის მოწყობილი.

## iPhone სხვა ქსელიდან

Expo Go-ში და კომპიუტერის Expo CLI-ში ერთსა და იმავე ანგარიშში შედი. შემდეგ:

```sh
npx expo start --tunnel ngrok
```

დაასკანერე ახალი QR კოდი iPhone-ის კამერით. ლეპტოპი და Expo-ს სერვერი ჩართული უნდა დარჩეს. Tunnel-ის მისამართი დროებითია და ყოველი გაშვებისას შეიძლება შეიცვალოს. Tunnel აპის სატესტო კოდს ngrok-ის მეშვეობით საჯარო მისამართიდან ხელმისაწვდომს ხდის.

## ენები

ყველა არსებულ ეკრანზე შესაძლებელია ქართული / English არჩევა. ნაგულისხმევი ენა ქართულია. არჩევანი AsyncStorage-ში ინახება და reload-ის შემდეგ აღდგება; ჯავშანი მხოლოდ სესიაში რჩება. თარგმანები: `src/i18n/translations.ts`. ენის შეცვლა თანხას, ვალუტას ან მიმდინარე ჯავშანს არ ცვლის.
